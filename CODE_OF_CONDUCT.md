# Code Of Conduct

## Our Pledge

We want `db-vwr` to be a respectful and productive project for everyone. Contributors and maintainers are expected to participate with empathy, professionalism, and care.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experiences.
- Give and receive constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Be patient with people who are learning or contributing in their spare time.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or behavior.
- Trolling, insults, or deliberately disruptive comments.
- Publishing private information without permission.
- Sexualized language, imagery, or attention.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior violates this code of conduct.

## Scope

This code applies in project spaces, including issues, pull requests, discussions, documentation, and other public or private project communication.
